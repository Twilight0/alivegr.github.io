## 🧩 Addon suite

Twilight0 develops open-source Kodi addons with an emphasis on Greek content. Everything below is distributed and updated through the [Twilight0 Repository](https://github.com/Twilight0/repository.twilight0) for Kodi 20 (Nexus) and 21 (Omega).

### 🌷 Tulip — the backbone

Every addon on this page is built on **Tulip**: a modern Kodi Python framework powering dialogs, directory listings, player controls, transliteration and much more. Its roots trace back to code by the legendary **"lambda"** — creator of Genesis and Exodus, whose work shaped an entire era of Kodi addons — carried forward and modernized for Python 3 and today's Kodi.

* Source: [github.com/Twilight0/script.module.tulip](https://github.com/Twilight0/script.module.tulip)

### 📺 AliveGR

The flagship video addon — one addon for everything Greek: live TV, movies, series, sports, music, radio, news, kids and documentaries, aggregated from freely available public sources. Nothing is hosted; it acts strictly as a directory and search client.

* Source: [github.com/Twilight0/plugin.video.alivegr](https://github.com/Twilight0/plugin.video.alivegr)
* Install: Twilight0 Repository → Video add-ons → AliveGR (see the [Install & FAQ](/en/install/) guide)

### ▶️ NewPipe

A privacy-first YouTube client for Kodi, following the NewPipe concept: no account, no API key, local-only subscriptions. Watch, search and subscribe without handing your viewing habits to Google.

* Source: [github.com/Twilight0/plugin.video.newpipe](https://github.com/Twilight0/plugin.video.newpipe)

### 🔌 PluginsGR

The resolver pack that powers Greek playback: dedicated resolvers for official Greek broadcast portals, complementing ResolveURL so streams extract fast and directly, without proxy overhead.

* Source: [github.com/Twilight0/script.module.resolveurl.pluginsgr](https://github.com/Twilight0/script.module.resolveurl.pluginsgr)
* Installed automatically as an AliveGR dependency via the repository

### 💬 Subtitles.gr

The dedicated Greek subtitles provider for Kodi: Subs4Free, GreekSubs.net, YIFI, TVsubtitles.net and Moviesubtitles.org with IMDb-ID matching — plus **automatic translation baked in**, powered by Google Translate, for subtitles that do not exist in your language. Opt-in SubDL and Subs4Series providers (via `curl_cffi`), and a global context-menu companion (`context.subtitles.gr`) for one-click downloads from any library item.

* Source: [github.com/Twilight0/service.subtitles.subtitles.gr](https://github.com/Twilight0/service.subtitles.subtitles.gr) · Companion: [github.com/Twilight0/context.subtitles.gr](https://github.com/Twilight0/context.subtitles.gr)

### 🧰 Dev ToolBox

A Swiss army knife for Kodi developers and power users: debugging helpers, maintenance actions and handy utilities in one program addon.

* Source: [github.com/Twilight0/plugin.program.devtoolbox](https://github.com/Twilight0/plugin.program.devtoolbox)

### 📻 E-Radio.gr

The premier Greek radio station addon, fully modernized: HTTPS streams, correct Greek labels, fuzzy search and fresh station lists without stale caches.

* Source: [github.com/Twilight0/plugin.audio.eradio.gr](https://github.com/Twilight0/plugin.audio.eradio.gr)

### 🎵 SomaFM

Listener-supported independent internet radio, rebuilt on the modern SomaFM JSON API: direct stream resolution per station ID, real-time localized song history, and instant cache invalidation so "Now Playing" is always current.

* Source: [github.com/Twilight0/plugin.audio.somafm.com](https://github.com/Twilight0/plugin.audio.somafm.com)
